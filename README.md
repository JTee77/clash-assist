# Clash伴侣 / Clash Assist

**简体中文** | [English](./README_EN.md)

**Clash伴侣**（Clash Assist）是一款专为 Mac（Apple Silicon 芯片）打造的小工具，用来帮你**检测手头的代理节点到底好不好用，并给每个节点评出直观的星级**。

很多时候我们在代理软件里点「测延迟」，看到的只是数字好看，真用起来却发现看不了视频、登不上 AI，或者网速很慢。**Clash伴侣**会把你的节点真正跑一遍，用大白话告诉你结果：

- ⭐ **节点好不好，一眼看星级**：自动把测完的节点按 1～5 星从高到低排好，哪个节点最稳、最值得日常主力使用，一目了然。
- 🤖 **能不能用 AI / 看流媒体**：直接帮你试好节点能不能正常用 **ChatGPT、Gemini**，以及能不能解锁 **Netflix、YouTube、Disney+、TikTok、Spotify** 等服务和对应地区。
- 🚀 **真实网速 & IP 纯净度**：实测节点的真实下载速度、响应延迟，并查清节点的实际落地国家和 IP 类型（是普通机房 IP 还是原生住宅 IP）。
- 🛡️ **上网环境安不安全**：一键检查当前代理设置有没有悄悄漏出你的国内真实 IP 或 DNS，以及国内外网站分流正不正常。
- 🔍 **按地区筛选 & 自动存结果**：节点太多也不用全测，可以只筛出「日本」「香港」或搜索关键词来测；测过的结果会自动保存，下次打开软件直接就能看。

> **目前支持的客户端**：**Clash Verge（Clash Verge Rev）**、**FlClash**。  
> *(注：本软件只是节点的「体检工具」，本身不提供任何节点或 VPN 服务。)*

## 下载与安装

从 [Releases 页面](https://github.com/JTee77/clash-assist/releases) 下载最新的 `.dmg` 安装包，打开后把 **Clash伴侣** 拖进「应用程序」即可。

### 首次安装或更新版本后，打开提示「无法验证」怎么办？

因为应用尚未购买苹果官方付费开发者公证（$99/年），**每次从浏览器下载安装或覆盖更新新版本后，第一次打开时** macOS 都会重新弹出安全拦截（同一版本放行后日常打开不会再弹）：

1. 弹窗里点 **「完成」**（不要点「移到废纸篓」）。
2. 打开 Mac 的 **系统设置 › 隐私与安全性**，滑到最下方，点 **「仍要打开」**。
3. 在弹出的确认框里再点一次 **「仍要打开」** 并输入开机密码确认。

> 💡 **老手快捷命令（可选）**：如果你觉得每次更新版本去系统设置里点太麻烦，拖入「应用程序」后在终端运行一行 `xattr -cr "/Applications/Clash Assist.app"` 即可直接双击打开。

### 关于「本地网络」权限弹窗

第一次点「环境泄漏检查」时，系统可能会问是否允许访问「本地网络」。这是因为检查 DNS 和真实 IP 泄漏需要探测本地路由器解析情况；允许即可，平时单纯测节点不需要这个权限。

## 怎么使用？

1. 先打开你的 **Clash Verge** 或 **FlClash**，正常连上一个节点。
   - *如果你用的是 **FlClash**，请先在 FlClash 的「设置 → 常规 → 入站」里把「外部控制器」开关打开。*
2. 打开 **Clash伴侣**，在顶部选择你正在用的软件，点击 **「获取节点」**。
3. 你可以：
   - 点某个节点卡片上的 **「测」**，单独给这一个节点做全面体检；
   - 或者先按地区筛选（比如只选「日本」），再点 **「测筛选节点」 / 「测全部节点」**，软件会自动帮你挨个测完、打出星级，并在结束后自动切回你原本正在用的节点。

## 命令行支持（进阶 / 自动化）

除了图形界面，Clash伴侣还内置了完整的命令行工具（与界面共享检测结果缓存）。运行一次安装命令后即可在终端直接使用 `clash-assist`：

```bash
"/Applications/Clash Assist.app/Contents/MacOS/clash-assist" --cli install-shim
clash-assist --cli help
```

详细用法见 [docs/CLI.md](./docs/CLI.md)（AI 助手调用指南见 [docs/AGENTS-CLI.md](./docs/AGENTS-CLI.md)）。

## 注意事项与免责声明

- **不提供代理服务**：本工具仅用于本地网络诊断与节点体检，不提供任何代理节点或 VPN 服务。
- **注意流量消耗**：深度测速会通过节点真实下载一小段测试数据以测算带宽，请留意你的订阅剩余流量。
- **检测结果仅供参考**：网站解锁与防泄漏检查基于实时抽样探测，受目标网站风控策略变化影响，结果供日常选节点参考。
